# Carpeta de investigación UX del editor

Esta carpeta conserva la investigación del editor como evidencia de producto, no como una lista de deseos visuales.

## Orden de trabajo

1. `00-protocolo-interno.md`: protocolo operativo derivado del prompt maestro.
2. `01-pagepilot-evidencia.md`: recorrido observado en PagePilot, con hechos e incertidumbres.
3. `02-tiendaiq-evidencia.md`: recorrido equivalente en TiendaIQ.
4. `03-hallazgos-y-aceptacion.md`: diferencias, prioridades y criterios verificables.
5. `04-pruebas-pendientes.md`: casos que todavía requieren repetición o mouse real.

La auditoría no considera una función terminada porque exista el código: exige que el movimiento sea observable en árbol, preview, historial, persistencia y estado del editor.
